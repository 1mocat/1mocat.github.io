Hello I'm

Chengquan Guo (郭城权)

I am a second-year PhD student in the Secure Learning Lab at the University of Chicago, advised by Prof. Bo Li and Prof. Ce Zhang. I study the safety and security of LLM agents, focusing on automated red teaming, prompt injection, and contextual privacy. Before that, I did my undergraduate studies at Zhejiang University (2021–2025). I was a research intern at Microsoft Research in Summer 2026.

Research

    "*" stands for equal contribution.

  • arXiv 2026Where You Inject Matters: The Trust Region Effect in LLM Agents

    Chengquan Guo, Xiaodong Liu, Weiwei Yang, Mingqian Feng, Jialin Song, Qiyao Ma, Carolyn Buractaon, Christopher White, Bo Li, Jianfeng Gao

    TL;DR: With the injection content held fixed, where an indirect prompt injection is placed strongly changes agent susceptibility: agents implicitly trust some regions of their environment (e.g., README/TODO files) more than others, and learned attackers can exploit this.

    Paper

  • arXiv 2026AgentCIScope: Grounded Contextual Integrity Evaluation for LLM Agents

    Chengquan Guo, Zhaorun Chen, Zinan Lin, Xiaodong Liu, Bo Li

    TL;DR: A platform and benchmark that turns privacy cases into executable multi-step agent tasks with grounded disclosure constraints; across 12 agents and 936 tasks, single-run leakage rates range from 32.5% to 94.4%.

    Paper

  • arXiv 2026DecodingTrust-Agent Platform (DTap): A Controllable and Interactive Red-Teaming Platform for AI Agents

    Zhaorun Chen, Xun Liu, Haibo Tong, Chengquan Guo, Yuzhou Nie, Jiawei Zhang, Mintong Kang, Chejian Xu, Qichang Liu, Xiaogeng Liu, Tianneng Shi, Chaowei Xiao, Sanmi Koyejo, Percy Liang, Wenbo Guo, Dawn Song, Bo Li

    TL;DR: The first controllable and interactive red-teaming platform for AI agents, spanning 14 real-world domains and 50+ simulated environments, with an autonomous red-teaming agent (DTap-Red) and a large-scale benchmark (DTap-Bench).

    Paper Code 🌐 Website

  • ICML 2026BlueCodeAgent: A Blue Teaming Agent Powered by Automated Red Teaming for CodeGen AI

    Chengquan Guo, Yuzhou Nie, Chulin Xie, Zinan Lin, Wenbo Guo, Bo Li

    TL;DR: An end-to-end blue-teaming agent that uses automated red teaming to generate risky cases, then defends via constitution summarization and dynamic code analysis, improving F1 by 14.7% on average across four code-safety tasks.

    Paper Code

  • ICLR 2026RedCodeAgent: Automatic Red-teaming Agent against Diverse Code Agents

    Chengquan Guo, Chulin Xie, Yu Yang, Zhaorun Chen, Zinan Lin, Xander Davies, Yarin Gal, Dawn Song, Bo Li

    TL;DR: The first automated red-teaming agent for code agents: an adaptive memory helps the agent select and combine jailbreak tools and attacks are judged by sandboxed execution, exposing new risks in real assistants such as Cursor and Codeium.

    Paper Code

  • NeurIPS 2025GUARDSET-X: Multi-Domain, Policy-Grounded, AI Security Guardrail Benchmark

    Mintong Kang*, Zhaorun Chen*, Chejian Xu*, Jiawei Zhang*, Chengquan Guo*, Minzhou Pan, Ivan Revilla, Yu Sun, Bo Li

    TL;DR: A guardrail benchmark covering eight safety-critical domains, with risks grounded in real domain-specific safety policies; benchmarking 19 guardrail models reveals limited domain coverage and vulnerability to adversarial attacks.

    Paper Code

  • NeurIPS 2024RedCode: Risky Code Execution and Generation Benchmark for Code Agents

    Chengquan Guo*, Xun Liu*, Chulin Xie*, Andy Zhou, Yi Zeng, Zinan Lin, Dawn Song, Bo Li

    TL;DR: A benchmark of 4,050 risky code-execution test cases (25 vulnerability types, evaluated in Docker) and 160 harmful code-generation prompts for assessing the safety of code agents.

    Paper Code 🌐 Website

    Other Publications

  • arXiv 2026CoFiBreak: A Coarse-to-Fine Diversity Reward for Effective Multi-Turn Jailbreak

    Jialin Song, Xiaodong Liu, Weiwei Yang, Mingqian Feng, Chengquan Guo, Qiyao Ma, Carolyn Buractaon, Anson Ho, Wuyang Chen, Christopher White

    TL;DR: A coarse-to-fine diversity reward for RL-trained multi-turn jailbreak attackers that prevents collapse onto near-duplicate attacks, finding 1.6–2.0× more distinct successful strategies while keeping attack success high.

    Paper

  • arXiv 2026ShallowDefend: Harnessing Shallow Safety Alignment for Multi-Turn Defender

    Qiyao Ma, Xiaodong Liu, Weiwei Yang, Mingqian Feng, Chengquan Guo, Jialin Song, Carolyn Buractaon, Zhe Zhao, Junshan Zhang, Sandeep Atluri, Christopher White, Jianfeng Gao

    TL;DR: Turns shallow safety alignment into a defense: the defender first commits to an explicit safety decision (Assess → Decide → Respond), trained with RL, achieving the strongest multi-turn safety while preserving utility.

    Paper

  • arXiv 2026SEMA-Auto: Sighted and Efficient Multi-Turn Attack with Autonomy

    Mingqian Feng, Xiaodong Liu, Weiwei Yang, Chenliang Xu, Jialin Song, Qiyao Ma, Chengquan Guo, Carolyn Buractaon, Mark Russinovich, Christopher White, Jianfeng Gao

    TL;DR: An autonomous multi-turn jailbreak attacker that reads the victim's replies and decides by itself when to stop, with no in-loop evaluator, reaching state-of-the-art attack success in nearly the fewest turns.

    Paper

  • arXiv 2026Beyond Math and Code: Lightweight Corpus-Grounded Process Rewards for Factual Question Answering

    Shicheng Fan, Haochang Hao, Dehai Min, Weihao Liu, Hanrong Zhang, Lingwei Wei, Henry Peng Zou, Chengquan Guo, Jie Yang, Honghui Bao, Zhiwei Liu, Lu Cheng, Philip S. Yu

    TL;DR: CorVer derives sentence-level factuality rewards from corpus co-occurrence statistics instead of neural verifiers, cutting RL training time by 5.5–10.4× while improving factual QA accuracy.

    Paper

  • arXiv 2025VulnLLM-R: Specialized Reasoning LLM with Agent Scaffold for Vulnerability Detection

    Yuzhou Nie, Hongwei Li, Chengquan Guo, Ruizhe Jiang, Zhun Wang, Bo Li, Dawn Song, Wenbo Guo

    TL;DR: The first specialized reasoning LLM (7B parameters) for vulnerability detection; with an agent scaffold it outperforms CodeQL and AFL++ on real-world projects and discovers zero-day vulnerabilities.

    Paper Code

  • ICLR 2025MMDT: Decoding the Trustworthiness and Safety of Multimodal Foundation Models

    Chejian Xu, Jiawei Zhang, Zhaorun Chen, Chulin Xie, Mintong Kang, Yujin Potter, Zhun Wang, Zhuowen Yuan, Alexander Xiong,
    Zidi Xiong, Chenhui Zhang, Lingzhi Yuan, Yi Zeng, Peiyang Xu, Chengquan Guo, Andy Zhou, Jeffrey Ziwei Tan, Xuandong Zhao,
    Francesco Pinto, Zhen Xiang, Yu Gai, Zinan Lin, Dan Hendrycks, Bo Li, Dawn Song

    TL;DR: The first unified platform for evaluating multimodal foundation models across safety, hallucination, fairness, privacy, adversarial robustness, and out-of-distribution generalization.
